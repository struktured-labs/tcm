# TCM Health - Traditional Chinese Medicine Wellness App

A beautiful static landing page for TCM Health, a Traditional Chinese Medicine wellness app coming soon to Android.

## Features

- **Modern Design**: Clean, responsive design with TCM-inspired aesthetics
- **Interactive Elements**: Smooth scrolling, animations, and form handling
- **Educational Content**: Information about TCM principles and the Five Elements
- **Email Capture**: Newsletter signup forms for early access notifications
- **Mobile Responsive**: Fully responsive design for all devices

## Local Development

To run the website locally:

```bash
# Using Python 3
python3 -m http.server 8000

# Or using Python 2
python -m SimpleHTTPServer 8000

# Or using Node.js http-server
npx http-server -p 8000
```

Then visit: `http://localhost:8000`

## TCM Five Elements

The website showcases the five fundamental elements in Traditional Chinese Medicine:

1. **Wood** (木) - Liver & Gallbladder - Growth & Flexibility
2. **Fire** (火) - Heart & Small Intestine - Joy & Warmth
3. **Earth** (土) - Spleen & Stomach - Stability & Nourishment
4. **Metal** (金) - Lung & Large Intestine - Structure & Clarity
5. **Water** (水) - Kidney & Bladder - Wisdom & Flow
